# PassATS AI — النسخة الخارجية

صفحة هبوط مبنية بـ HTML و CSS لعرض فكرة PassATS AI للمستخدمين.  
توضح كيف يساعد النظام في تحسين السيرة الذاتية ورفع نسبة اجتياز أنظمة ATS.

---

## المحتوى
- تعريف بالمشروع
- عرض المميزات الأساسية
- شرح طريقة عمل النظام
- زر الدخول للنسخة الداخلية
- تصميم عربي خفيف وسريع
